# 饥荒联机版服务器搭建：2核4G云服务器起步，从装 SteamCMD 到队友能进服

房主开电脑、队友输 IP 直连，这套玩法在饥荒里撑不过三天。房主一下线，房间直接没了；家庭宽带的公网 IP 每次重启都在变，你还得重新发一遍地址；电脑同时跑客户端和服务端，到冬天打巨鹿那阵子卡得像幻灯片。

自己开一台云服务器能一次性解决这三个问题：24 小时在线、固定公网 IP、资源独立。剩下的问题只有一个——怎么搭。这篇文章给两条路，一条是给不想碰命令行的，一条是给想自己控制全部配置的。

## 先选路线：面板一键开服，还是自己装

雨云的游戏云提供了两种形态，对饥荒的处理方式完全不同：

**MCSM 面板服**：基于开源的 MCSManager 面板，雨云官方文档里明确写了支持一键部署的游戏包含 Minecraft Java 版、基岩版、泰拉瑞亚和**饥荒**。全程网页操作，开服、看控制台、改配置文件、上传 mod 都在浏览器里完成，还支持 SFTP。适合"我只想让朋友进来玩"的场景。

**纯 Linux 环境（Docker）或游戏云 VPS**：给你一台真正的机器，装什么、怎么装随你。饥荒服务端从 SteamCMD 拉，cluster.ini 自己写，mod 手动更新。适合要挂一堆 mod、想开多存档、或者以后还想顺手跑点别的东西的人。

| 路线 | 上手难度 | 需要会用 | 适合 |
| --- | --- | --- | --- |
| MCSM 面板服 | 低 | 只会上网 | 好友档、单存档、不想维护 |
| 纯 Linux 环境 / 游戏云 VPS | 中 | SSH 基础命令 | 多存档、多 mod、想长期折腾 |

选好路线再谈配置，不然容易买贵或者买亏。

## 配置怎么选：内存是硬指标，带宽别低于 5M

饥荒服务端的资源占用跟"几个人玩"关系不大，跟"开了几个世界"关系很大。一个正常的存档跑满——地上世界加地下洞穴两个 shard——公开的服务器管理脚本项目（GitHub 上的 Linux_DST_SCRIPT）给出的实测参考是**占用 1.5G 到 2G 内存**。

所以配置的算法很简单：

- **1 个存档（地上+地下）**：2 核 4G 起步，这是目前比较通行的建议配置，公开教程里给到饥荒联机版的推荐也是 2 核 4G、带宽 5–8Mbps
- **2 个存档或重 mod 服**：4 核 8G，留出余量，别等崩档了才想起来升级
- **硬盘**：30G 够用，但存档和备份会慢慢涨，留点空间

带宽这块容易被忽略。饥荒的同步频率不低，玩家人数上来后小水管会明显拖后腿。雨云游戏云 VPS 入门级给的是 10M 上行，进阶级 15M，超高端 20M，往下再看还得配 200M 的下行,这个量级对饥荒是够的。

另外雨云的游戏云用的是专用高主频 CPU（Intel i9 14900KF、13900KF、Ryzen 9950X、7950X、5900X、Gold 6146、E5 2666v3 这几种），官方说明里直接写了这类机型适合需要高单核性能的游戏服务端。饥荒服务端对多核利用率一般，CPU 主频比核心数更值得看，这点上选游戏云比选通用型云服务器更对路。

## 自己搭：SteamCMD 装服务端

以下以 Ubuntu 为例，装服务端要动到 32 位依赖，这部分是最容易报错的地方。

先补依赖：

bash
sudo dpkg --add-architecture i386
sudo apt update
sudo apt install -y lib32gcc-s1 lib32stdc++6 zlib1g:i386 libcurl4:i386 libc6:i386 libstdc++6:i386


装 SteamCMD：

bash
mkdir -p ~/steamcmd && cd ~/steamcmd
wget https://steamcdn-a.akamaihd.net/client/installer/steamcmd_linux.tar.gz
tar -xvzf steamcmd_linux.tar.gz
./steamcmd.sh


进入 `Steam>` 提示符后，装饥荒服务端。饥荒服务端的 app id 是 **343050**，注意路径必须写绝对路径，SteamCMD 不认 `~` 这种写法：


force_install_dir /home/你的用户名/server_dst
login anonymous
app_update 343050 validate
quit


装完先验一下依赖有没有缺：

bash
ldd ~/server_dst/bin/dontstarve_dedicated_server_nullrenderer


如果输出里有 `not found`，按提示补对应包。老教程里常见的一个坑是缺 `libcurl-gnutls.so.4`，可以用软链接指过去。真正启动时如果缺 64 位版本，用的是 `dontstarve_dedicated_server_nullrenderer_x64`。

## cluster_token 和 cluster.ini：连不上的问题八成在这

服务端文件装好了不代表能开服，饥荒还要求一个存档目录，里面至少要有两样东西。

**cluster_token.txt**：登录 Klei 账号，进"游戏服务器"页面，添加一个新服务器，复制生成的那串字符，写进这个文件。没有它，服务端会直接拒绝启动。

**cluster.ini**：服务器名字、密码、人数上限、PVP 开关、是否双 shard 都在这里。一个能跑的最小配置长这样：

ini
[GAMEPLAY]
game_mode = survival
max_players = 6
pvp = false
pause_when_empty = true

[NETWORK]
cluster_name = 你们的服务器名
cluster_password = 设置一个密码
cluster_description = 欢迎来玩
cluster_intention = cooperative

[MISC]
console_enabled = true

[SHARD]
shard_enabled = true
shard_count = 2
cluster_key = 自己随便定一串字符


目录结构是固定的：`~/.klei/DoNotStarveTogether/Cluster_1/` 下面要有 `Master`（地上）和 `Caves`（地下）两个文件夹，加上 `cluster.ini` 和 `cluster_token.txt`。

省事的做法是在自己电脑的游戏里正常创建一次存档，创建完退出，然后把本地 `Cluster_1` 文件夹整个用 SFTP 传到服务器上覆盖——世界生成选项、mod 配置全都跟着过去了，比手写 `worldgenoverride.lua` 快得多。

## 启动、验证、进服

两个 shard 要分别启动，第一次启动一般会提示"Your Server Will Not Start"，那是正常的，因为还没填 token。用 `screen` 让服务端在断开 SSH 后继续跑：

bash
cd ~/server_dst/bin
screen -S dst_master
./dontstarve_dedicated_server_nullrenderer -console -cluster Cluster_1 -shard Master


按 `Ctrl+A` 再按 `D` 把这个会话挂到后台，然后同样方式再起一个 Caves。命令里带 `-console` 是打开交互式控制台，回档、发公告、复活玩家都靠它。

队友进服的方式有三种：在游戏内服务器列表里搜你设的 `cluster_name`、通过 Steam 好友列表加入、或者在 Steam 启动项里填 `+connect IP:端口`。如果前两种都看不到服务器，直接让人试第三种，能连上就说明服务端没问题，是列表可见性的问题。

## 维护：备份、自启、跟着游戏更新

三件必须做的事：

**备份存档。** 存档全在 `~/.klei/DoNotStarveTogether/Cluster_1/` 里，定期打包拖走就行。真丢了就是一整季白玩。

**崩档自启。** 饥荒服务端崩了不会自己起来，线上没人看着的时候，房间就那么挂了一整晚。公开的 Linux_DST_SCRIPT 这类脚本能自动检测进程、崩溃重启、每 5 小时备份一次存档并保留几天，不想自己写监控的话直接拿来用。

**跟着更新。** 每次饥荒官方更新，服务端都要重新拉一次（再跑一遍 `app_update 343050 validate`），否则客户端会因为版本不一致连不上。mod 同理。

## 几个高频问题

**买回来控制台显示已启动，队友还是进不去？** 九成是端口没放开。NAT 机型要去后台做端口映射，把 `10999/UDP` 映射出去，缺一步都不行。

**需要独立公网 IP 吗？** 雨云游戏云 VPS 默认是 NAT 机型，多个用户共享公网 IP，通过端口映射对外提供服务，对饥荒来说够用。如果你的场景必须独占 IP（比如某些监控工具或需要指定端口直连），部分机型支持加购独立公网 IP。

**服务器会卡吗？** 先看内存：地上+地下跑满 2G，2核4G 机器再跑别的就紧张了。再看带宽：人数多了小带宽是瓶颈。两个都不是问题的话，检查一下服务端的视距和实体数量设置。

**一定要用 Ubuntu 吗？** 不是。Windows 也能跑，雨云游戏云 VPS 支持 Windows 和 Linux 系统任选，只是 Linux 下用 screen/tmux 维护更省心，内存占用也更低。

**能不能不用命令行？** 能。选 MCSM 面板服，官方面板本来就把饥荒列在一键开服的支持列表里，全程网页操作。
